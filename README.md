# Odyssey

**XP bar & leveling tracker** for World of Warcraft: Forever (Classic).

- A clean custom XP bar (three styles, four themes) that replaces the default one.
- Rested XP and "quests ready to turn in" drawn right on the bar.
- Three text slots you choose freely: percentage, current / max, remaining, rested, XP per hour, time to level, kills to level, quest XP, level.
- A detailed tooltip: level totals, rested XP, **quest-by-quest XP**, session pace, kills to level, time played.
- A **leveling history**: how long each level took and how your current pace compares with your own average.

## Usage

- `/odyssey` or right-click the bar: settings.
- `/odyssey unlock` then drag the bar; `/odyssey lock` to fix it.
- `/odyssey reset`: restart the session figures.

## Known limitation

On this client the default XP and reputation bars share one container, so hiding the default XP bar
also hides the reputation bar. Turn off "Hide Blizzard XP bar" to get it back. An Odyssey reputation
bar is planned.

## Install

Install from CurseForge, or copy this folder to `World of Warcraft/_classic_beta_/Interface/AddOns/Odyssey`.

## Development

Pure logic is unit-tested outside the game:

    luajit tests/run.lua

Textures are generated by `python3 tools/make_textures.py`. See `docs/` for the design and the plan.
